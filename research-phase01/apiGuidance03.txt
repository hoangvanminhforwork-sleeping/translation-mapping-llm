Use morph/reflex with the OpenRouter API:

This model does not generate text. It answers typed questions about a state (a string, object, or array) through the Decisions API and returns calibrated probabilities: a yes/no probability (noul), a pick from options you define (choice), or a position on an ordered rubric (score). Your code owns the workflow and acts on the answers, so use it for routing, ranking, verification, and other structured decisions rather than chat. Learn how to build with System One.

Some decisions models also take images, audio, or video as parts of the state array, in the same shapes as chat message content; the example above matches what this model accepts. Learn more about multimodal decisions.

In the examples below, the OpenRouter-specific headers are optional. Setting them allows your app to appear on the OpenRouter leaderboards.

import fs from "fs";
import { OpenRouter } from "@openrouter/sdk";

const openrouter = new OpenRouter({
  apiKey: "<OPENROUTER_API_KEY>"
});

const imageBase64 = (await fs.promises.readFile("image.png")).toString("base64");

// The model answers narrow, typed questions about the state. Your code owns the workflow.
const decision = await openrouter.alpha.decisions.create({
  decisionsRequest: {
    model: "morph/reflex",
    state: [
      "Listing: vintage red bicycle, light scratches on the frame",
      { type: "image_url", image_url: { url: `data:image/png;base64,${imageBase64}` } }
    ],
    questions: {
      matches_listing: {
        type: "noul",
        instructions: "Does the attached media show the listed item?",
        criteria: {
          true: "The listed item is shown",
          false: "Something else or nothing is shown"
        }
      },
      category: {
        type: "choice",
        instructions: "Which category fits this listing?",
        criteria: {
          bikes: "Complete bicycles",
          parts: "Components and accessories",
          apparel: "Clothing and gear"
        }
      },
      condition: {
        type: "score",
        instructions: "How worn is the item?",
        criteria: ["Like new", "Light wear", "Heavy wear"]
      }
    }
  }
});

const { matches_listing, category, condition } = decision.answers;
if (matches_listing.type === "noul" && category.type === "choice" && condition.type === "score") {
  // noul is a probability from 0 (no) to 1 (yes); choice and score carry the full distribution.
  console.log(matches_listing.noul, category.choice, category.probabilities, condition.score);
  if (matches_listing.noul > 0.8 && category.choice === "bikes") {
    // publishListing(...)
  }
}
